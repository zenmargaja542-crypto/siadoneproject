# Study Tracker App

Frontend-only project built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard with progress overview
- Subjects list with add/delete
- Study timer (Pomodoro-style)
- Resources library
- Achievements/stats

## Sign-in & sign-up
- **Email + password** sign-up and log-in, plus Google (Gmail), Facebook and GitHub — all via Firebase Authentication. Run `SETUP-WIZARD.html` for a guided setup (or follow `AUTH-SETUP.md`).
- One-click **⚡ Instant demo sign-in** works offline with no account — sign in immediately and add your Firebase config anytime for real accounts.
- The login screen shows a "⚙️ Enable real sign-in" panel until a Firebase config is saved; demo mode stays available offline.
- Each account gets its own private data space on the device.

## Tech Stack
- HTML, CSS, JavaScript
- LocalStorage for persistence
- Responsive design

## Run
Clone the repo, then open `index.html` in your browser.
