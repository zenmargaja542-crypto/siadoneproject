Real sign-in setup wizard

Real Google · Facebook · GitHub login in ~10 minutes. The account clicks need your passwords — this wizard makes every step obvious and copies the tricky URLs for you.

⚠️ You opened this page as a local file (file://). Sign-in windows cannot work this way. After setup, double-click start-server.bat in this folder and open http://localhost:8000 (or use the VS Code Live Server extension).
1

Create a free Firebase project & register the web app

  1. Add project → name it (e.g. study-tracker) → Continue → Create.
  2. On the project page click the Web icon </> → nickname study-tracker → Register app (skip Hosting).
  3. Firebase shows a firebaseConfig block — you'll paste it in Step 3.
🌐 Open console.firebase.google.com
2

Enable Google, Facebook & GitHub sign-in

  1. Open Authentication → Get started (button below). Set a support email if asked.
  2. Email/Password → enable it (usually already on) — this powers the Create account and Sign in forms on the app. ✅
  3. Google → Enable → choose your email → Save. ✅ Nothing else needed.
  4. Facebook: create an app at Facebook for developers (type Consumer, add the Facebook Login product) → Settings → Basic → copy the App ID + App Secret → paste them into Firebase's Facebook provider → Save. Then put your callback URL (generated in Step 3) into Facebook Login → Settings → Valid OAuth Redirect URIs.
  5. GitHub: create an OAuth App on GitHub → paste the callback URL (from Step 3) → register → copy the Client ID + Client Secret into Firebase's GitHub provider → Save.
  6. Authentication → Settings → Authorized domains: add localhost (usually already there) and your live domain later (e.g. yourname.github.io).
🔐 Firebase Authentication 📘 Facebook for developers 🐙 GitHub OAuth Apps
3

Paste your firebaseConfig — get your exact callback URLs

  1. In Firebase open ⚙️ Project settings → Your apps (button below) → copy the whole firebaseConfig block.
  2. Paste it below and press Check my config — the wizard builds the exact URLs Facebook/GitHub need.
⚙️ Project settings
4

Activate — save the config & try real sign-in

Click the button: it saves your config into this browser and switches the app to real sign-in (when the app is opened the same way as this page).

  1. Open index.html → the same way you opened this page (Live Server / same server).
  2. Click Continue with Google / Facebook / GitHub → the real provider window opens → approve → you're signed in with your real name, email & avatar 🔒
  3. If a red toast appears, read it — it names the exact fix (usually adding this domain under Authentication → Settings → Authorized domains).

Remove anytime: app login screen → ⚙️ Enable real sign-in → "Remove saved config".
